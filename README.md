# اورژانس خودرو | EMSCar (Auto Emergency — Suggested English Name)

سامانه جامع عملیاتی، دیسپچ هوشمند، قیمت‌گذاری شفاف، پرداخت ایمن و مدیریت ناوگان **امداد خودرو** با تمرکز راه‌اندازی اولیه در **استان قزوین** و معماری آماده گسترش تدریجی و کنترل‌شده به کل کشور.

> **توجه درباره هویت برند:** نام اصلی سامانه **«اورژانس خودرو»**، نام مخزن **EMSCar** و نام انگلیسی *Auto Emergency* صرفاً یک نام پیشنهادی فنی (غیرثبت‌شده به‌عنوان علامت تجاری) است.

## ویژگی‌های کلیدی پیاده‌سازی‌شده

- **پوشش جغرافیایی فاز اول (استان قزوین):** فعال بودن انحصاری استان قزوین (قزوین، البرز/الوند، تاکستان، آبیک، بوئین‌زهرا، محمدیه/مهرگان و محورهای آزادراهی قزوین-کرج و قزوین-زنجان) با مسدودسازی سمت سرور برای مناطق غیرفعال و فرآیند ممیزی‌شده فعال‌سازی استان جدید توسط مدیر ارشد.
- **کاتالوگ ۱۵ خدمت تخصصی امداد خودرو:** باتری‌به‌باتری، تعویض باتری در محل، پنچرگیری سیار، تعویض زاپاس، سوخت‌رسانی اضطراری، باز کردن مجاز در خودرو (با الزام احراز مالکیت)، عیب‌یابی اولیه، تعمیرات سبک در محل، تعویض قطعات در محل، حمل با یدک‌کش، حمل به تعمیرگاه، حمل با کفی به مقصد دلخواه، خدمات ویژه خودروهای داخلی و خارجی، و امداد تخصصی خودروهای برقی (EV با الزام گواهی ولتاژ بالا).
- **۴ نقش کاربری با کنترل دسترسی سمت سرور (RBAC):**
  - `customer` (مشتری): مدیریت خودروها، ثبت درخواست با نقشه تعاملی/GPS/نشانی دستی، پیش‌فاکتور شفاف، پایش زنده امدادگر، تأیید تغییر قیمت نهایی، پرداخت، دریافت فاکتور چاپی، امتیازدهی و ثبت تیکت پشتیبانی.
  - `responder` (امدادگر): تکمیل مدارک هویتی/فنی و شبا، آنلاین‌شدن **صرفاً پس از تأیید مدارک و فعال‌سازی مدیر**، پذیرش اتمیک مأموریت بدون تداخل هم‌زمان، ثبت مراحل اعزام/رسیدن/شروع/گزارش پایان کار، و کیف پول و درخواست تسویه شبا.
  - `operator` (اپراتور پشتیبانی و مرکز پیام): پایش صف زنده مأموریت‌ها، مدیریت پرونده‌های بدون امدادگر آزاد (بدون نمایش ETA دروغین به مشتری)، تخصیص دستی، یادداشت‌های محرمانه داخلی و رسیدگی به شکایات.
  - `admin` (مدیر ارشد): داشبورد KPI عملیاتی و مالی، تأیید/تعلیق امدادگران، مدیریت کاتالوگ خدمات و ضرایب تعرفه، مدیریت استان‌ها و زون‌ها، بازپرداخت وجه (Refund)، تسویه شبا، مدیریت کاربران و مشاهده لاگ‌های ممیزی و امنیتی.
- **یکپارچگی مالی بر پایه تومان صحیح:** ذخیره تمامی مبالغ با واحد صریح تومان (`_toman`)، تبدیل خودکار به ریال صرفاً در مرز درگاه بانکی، استعلام سمت سرور Callback پرداخت، ضدتکرار تراکنش و شفافیت کامل حالت آزمایشی (`Sandbox`) در صورت عدم تنظیم درگاه واقعی.

## راه‌اندازی سریع در محیط توسعه

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای Migrationها و داده‌های نمونه محیط توسعه (صرفاً غیرعملیاتی)
npm run db:migrate
npm run db:seed:dev

# ۳. اجرای هم‌زمان سرور API و رابط کاربری روی 0.0.0.0:3000
npm run dev
```

### حساب‌های آزمایشی محیط توسعه (`APP_ENV=development` — غیرفعال در Production)

| نقش | شماره موبایل | رمز عبور | توضیح |
|---|---|---|---|
| مدیر ارشد (`admin`) | `09120000001` | `Admin@1405!` | دسترسی کامل مدیریتی و فعال‌سازی استان‌ها |
| اپراتور (`operator`) | `09120000002` | `Operator@1405!` | میز فرماندهی دیسپچ و پشتیبانی |
| امدادگر تأییدشده (`responder`) | `09120000011` | `Responder@1405!` | واحد امداد سیار فعال در شهر قزوین |
| امدادگر خودروبر (`responder`) | `09120000012` | `Responder@1405!` | کفی خودروبر فعال در قزوین و آزادراه |
| امدادگر متخصص EV (`responder`) | `09120000013` | `Responder@1405!` | دارای گواهی ایمنی خودروهای برقی |
| امدادگر در انتظار تأیید (`responder`) | `09120000014` | `Responder@1405!` | مسدود برای عملیات تا تأیید مدارک توسط ادمین |
| مشتری نمونه (`customer`) | `09120000021` | `Customer@1405!` | دارای خودروی پژو ۲۰۷ و خودروی برقی KMC E50A |

## دستورات تست، کنترل کیفیت و عملیات دیتابیس

```bash
npm run typecheck     # بررسی کامل TypeScript کلاینت و سرور
npm test              # اجرای مجموعه تست‌های خودکار واحد و یکپارچه (Vitest + Supertest)
npm run build         # ساخت نسخه Production کلاینت و سرور
npm run db:status     # وضعیت Migrationها
npm run db:backup     # تهیه پشتیبان اتمیک آنلاین از پایگاه‌داده
npm run db:rollback   # بازگردانی آخرین Migration
```
